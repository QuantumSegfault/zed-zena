# Zed Zena

[Zena](https://zena-lang.dev/) language extension for the [Zed](https://zed.dev/) editor.

It provides LSP support via `zena-cli`'s own [builtin language server](https://zena-lang.dev/reference/language-server/).

It does not provide any syntax highlighting support at the moment, as there is no tree-sitter grammar available for the language.
